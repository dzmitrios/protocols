## Purpose

Выдаёт короткоживущий токен доступа, чтобы названный участник вошёл в одну названную голосовую комнату. Сервер токенов не переносит аудио.

## ADDED Requirements

### Requirement: Issue a room token
Токен-сервер SHALL принимать имя комнаты и имя участника и возвращать подписанный токен. Идентичность токена SHALL совпадать с переданным именем участника. Разрешение SHALL позволять войти, публиковать и подписываться только в этой комнате.

#### Scenario: Valid request
- **WHEN** клиент отправляет непустое имя комнаты и непустое имя участника
- **THEN** сервер отвечает токеном с этой идентичностью и с разрешением войти, публиковать и подписываться в этой комнате

### Requirement: Return the media server address
Ответ с токеном SHALL включать адрес медиасервера, к которому клиент должен подключиться. Адрес SHALL браться из конфигурации сервера.

#### Scenario: Token response includes the server address
- **WHEN** токен выдан
- **THEN** тело ответа содержит и токен, и настроенный адрес медиасервера

### Requirement: Reject incomplete requests
Токен-сервер SHALL отклонять запрос, в котором имя комнаты или имя участника отсутствует или состоит из пробелов, и SHALL NOT возвращать токен.

#### Scenario: Missing room name
- **WHEN** имя комнаты отсутствует или пустое
- **THEN** сервер отвечает ошибкой клиента и не возвращает токен

#### Scenario: Missing participant name
- **WHEN** имя участника отсутствует или пустое
- **THEN** сервер отвечает ошибкой клиента и не возвращает токен

### Requirement: Keep signing secrets on the server
Токен-сервер SHALL подписывать токены учётными данными, доступными только серверу. Ответ SHALL NOT содержать секрет подписи.

#### Scenario: Secret is not in the response
- **WHEN** токен выдан
- **THEN** тело ответа содержит токен и не содержит секрет подписи

### Requirement: Identity is the participant name
Идентичность токена SHALL быть в точности переданным именем участника. Сервер SHALL NOT добавлять суффикс уникальности.

#### Scenario: Same name requested twice
- **WHEN** два запроса используют одно и то же имя участника
- **THEN** оба токена несут эту идентичность без добавленного суффикса
